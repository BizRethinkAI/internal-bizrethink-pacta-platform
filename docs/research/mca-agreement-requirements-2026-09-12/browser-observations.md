# Browser access observations — September 12, 2026

These are reviewer notes from public publisher pages opened in Chrome. They
are **not raw HTTP archives**. No response hash or exact original retrieval time
is asserted. The independently downloaded PDFs/text and their hashes are in
the [manifest](manifest.json). These browser checks read legal sources; they
were not application UI tests.

## Georgia public code and annual summaries

The legislature's navigation links “Georgia Code” to
[Lexis public access](https://www.lexisnexis.com/hottopics/gacode). Searching for
`10-1-393.18` returned the commercial-financing section. The displayed history
identified Code 1981, §10-1-393.18, enacted by Ga. L. 2023, p. 255, §2/SB 90,
effective January 1, 2024. The full section link encountered a CAPTCHA; no
attempt was made to bypass it. Full-body comparison against current code
therefore remains open.

The [legislature's general-statutes page](https://www.legis.ga.gov/general-statutes)
provided the observed 2024, 2025 and 2026 summary PDF links used in the manifest.
Those PDFs were downloaded directly, searched in full for the MCA section and
terms, and their full Title 10 sections read. Their limited corroborative value
is explained in the report. A guessed `/georgia-code` route produced an error
page in the browser despite an HTTP 200 application shell; it is not evidence
of a code section's absence.

## New York statute fallback

Direct requests for FIS §§801–812 returned HTTP 403. The web tool supplied the
complete legal bodies of 801–808 and 810–812. Its saved text did not supply 809,
so [§809](https://www.nysenate.gov/legislation/laws/FIS/809) was read in Chrome.
The page displayed the most recent revision as January 7, 2022. The complete
short section was transcribed into [the retained Article 8 text](evidence/ny-fis-801-812.txt).
Its signature duty concerns disclosures before the recipient proceeds further
with the transaction application; it does not prescribe an FRPA clause.

catalog check, **not** an end-to-end reading of all those generally applicable
rules. It supplements the [DFI FAQ](evidence/ut-dfi-faq.pdf), whose January 1,
2023 effective marker and no-format-rules statement are preserved. An initial
homepage search lost its query during navigation; no conclusion relies on that
unsuccessful search.
