# docs/counsel-is-professional-engagement — remove speculation recorded as fact

**PR:** #TBD. Docs only.

## What this removes

The Blocked entry for the clause library named a specific individual as the
attorney candidate and worked through an adverse-interest analysis (Fla. Bar R.
4-1.7, 4-1.8(i)) about their household being the tenant, concluding with a
"split agreed".

**No such thing was agreed.** It was a passing thought that got written into
`STATE.md` and then read back — by me, repeatedly today — as a settled
constraint. I cited it to the user as a reason the counsel path was shaped a
certain way, and built reasoning on top of it across several PR descriptions.

Library review is a professional engagement with counsel retained for it. That
is all the entry needed to say.

## Why removed rather than corrected in place

`STATE.md` is the file that answers "where do things stand" for a session with
no other memory. Its whole value is that everything in it can be trusted at the
same level. A speculation written in the same voice as a fact is worse there
than in any other file, because the next session has no way to tell them apart —
and did not.

A short note records that the passage existed and was removed, so the deletion
itself is not a mystery to anyone who saw the old text.
